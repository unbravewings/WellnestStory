# เส้นทางสุขภาพของคุณ — Optimal Health Companion

แอปติดตามเป้าหมายลดน้ำหนักคู่กับโปรแกรม Nutrilite สำหรับลูกค้าและทีมงาน

## สิ่งที่แอปนี้ทำ

- เช็กอินน้ำหนัก / รอบเอว / พลังงานประจำวัน
- แถบลายผ้าขิดแสดงสายต่อเนื่อง (streak) — จุดเด่นที่แยกทีมของคุณจากทีมอื่น
- กราฟความคืบหน้าน้ำหนัก
- เคล็ดลับประจำวันแบบพลิกการ์ด เนื้อหาปรับให้เข้ากับอาหารอีสาน
- เหรียญรางวัลตามความคืบหน้า
- การ์ดสรุปผลที่ดาวน์โหลดเป็นรูปภาพเพื่อแชร์ลง IG ได้ทันที

## ข้อมูลเก็บที่ไหน

ข้อมูลทั้งหมด (น้ำหนัก, streak, เป้าหมาย) ถูกบันทึกไว้ใน **เบราว์เซอร์ของอุปกรณ์ผู้ใช้เอง** (localStorage) ไม่มีการส่งข้อมูลไปเซิร์ฟเวอร์ใดๆ ทั้งสิ้น จึงไม่มีค่าใช้จ่ายด้านฐานข้อมูล และไม่ต้องกังวลเรื่องความเป็นส่วนตัวของลูกค้า

ข้อควรรู้: ถ้าลูกค้าล้างข้อมูลเบราว์เซอร์ (clear browsing data) หรือเปลี่ยนเครื่อง/เปลี่ยนเบราว์เซอร์ ข้อมูลเก่าจะหายไปและต้องเริ่มใหม่ เหมาะกับการใช้งานส่วนตัวบนมือถือเครื่องเดียวที่ลูกค้าใช้ประจำ

## วิธีอัปโหลดขึ้น GitHub และเปิดใช้งานฟรี (GitHub Pages)

1. สร้าง repository ใหม่บน GitHub (public repo ก็เพียงพอ) เช่นชื่อ `esan-wellness-companion`
2. อัปโหลดไฟล์ `index.html` และ `README.md` นี้เข้าไปใน repository (ลากไฟล์วางในหน้าเว็บ GitHub ได้เลย ไม่ต้องใช้คำสั่งใดๆ)
3. ไปที่ repository → **Settings** → **Pages**
4. ในหัวข้อ **Build and deployment** เลือก Source: **Deploy from a branch**
5. เลือก Branch: `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
6. รอประมาณ 1-2 นาที จะได้ลิงก์เว็บไซต์ในรูปแบบ:
   `https://<ชื่อบัญชี-github>.github.io/esan-wellness-companion/`
7. ส่งลิงก์นี้ให้ลูกค้าเปิดผ่านมือถือ แนะนำให้เพิ่มลงหน้าจอหลัก (Add to Home Screen) เพื่อให้เปิดใช้ได้เหมือนแอป

ไม่ต้องติดตั้งโปรแกรมใดๆ เพิ่มเติม ไม่มีค่าใช้จ่าย และทีมงานทุกคนสามารถแก้ไขเนื้อหา (เช่น เคล็ดลับประจำวัน สี ข้อความ) ได้โดยตรงในไฟล์ `index.html` แม้ไม่มีพื้นฐานเขียนโปรแกรม เพราะทุกอย่างอยู่ในไฟล์เดียว

## การปรับแต่งที่ทำได้ง่าย

- เพิ่ม/แก้เคล็ดลับประจำวัน: แก้ในตัวแปร `TIPS` ช่วงต้นของ `<script>`
- เปลี่ยนสี: แก้ค่าตัวแปรใน `:root { }` ช่วงต้นของ `<style>`
- เปลี่ยนชื่อแอปหรือข้อความ: แก้ข้อความใน `<body>` ได้โดยตรง

## ข้อจำกัดที่ควรทราบ

- ไม่มีระบบบัญชีผู้ใช้ (login) — เหมาะกับการใช้ส่วนตัวต่อเครื่อง ไม่เหมาะกับการดูข้อมูลลูกค้าหลายคนจากส่วนกลาง
- หากต้องการให้ทีมงานเห็นภาพรวมความคืบหน้าของลูกค้าทุกคน จะต้องอัปเกรดเป็นระบบที่มีฐานข้อมูลกลาง (เช่น Google Sheets หรือ Firebase) ซึ่งเป็นขั้นต่อไปที่ทำได้เมื่อพร้อม
