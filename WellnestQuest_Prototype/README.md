# 7 Days Wellnest Story Quest

เควสประจำวันคู่กับโปรแกรมลดน้ำหนัก Nutrilite — สุ่มเควส Eating Quest / Activity Quest ให้ลูกค้าทำวันละ 1 อย่างต่อประเภท พร้อมระบบ "เพื่อนสุขภาพ" (virtual pet) ที่โตขึ้นตามความสม่ำเสมอของลูกค้า

## ฟีเจอร์หลัก

- **เควสรายวัน**: หน้าแรกมีปุ่ม 2 ประเภท คือ อาหาร (Eating Quest) และ กิจกรรม (Activity Quest) แต่ละประเภทมี 4 หมวดย่อยให้เลือก 1 หมวดต่อวัน ระบบจะสุ่มเควส 1 อย่างจากหมวดที่เลือก
- **ล็อกถึงเที่ยงคืน**: เควสที่สุ่มได้จะค้างอยู่จนถึง 00:00 ตามเวลาเครื่องของลูกค้า กันไม่ให้สุ่มใหม่ไปเรื่อยๆ จนกว่าจะได้เควสง่าย เมื่อถึงเที่ยงคืนจะรีเซ็ตให้เลือกใหม่ได้อัตโนมัติ พร้อมตัวนับถอยหลังแสดงเวลาที่เหลือ
- **Day Streak**: นับจำนวนวันติดต่อกันที่ทำสำเร็จทั้ง 2 ประเภทในวันเดียวกัน ขาดวันใดวันหนึ่งจะรีเซ็ตนับใหม่
- **เพื่อนสุขภาพ (Virtual Pet)**: วงแหวนความคืบหน้ารอบตัวเพื่อนสุขภาพจะค่อยๆ เติมเต็มทีละวัน (แบบสะสม ไม่ต้องติดต่อกัน) ทุกๆ 7 วันที่ทำสำเร็จ เพื่อนจะเติบโตขึ้น 1 ขั้น รวมทั้งหมด 6 ขั้น (ประมาณ 6 สัปดาห์ของความสม่ำเสมอ) ตอนนี้ใช้ข้อความ "Pet 1" ถึง "Pet 6" เป็นตัวแทนชั่วคราว รอเปลี่ยนเป็นภาพจริงภายหลัง
- **การ์ดแชร์**: ปุ่ม "บันทึกรูปสัตว์เลี้ยง" สร้างการ์ดสัดส่วน 9:16 พร้อมโลโก้ Wellnest Story, ขั้นการเติบโต, จำนวนวันสะสม และ Day Streak ดาวน์โหลดเป็นรูปเพื่อแชร์ลง IG Story ได้ทันที

ข้อมูลทั้งหมดเก็บไว้ใน localStorage ของเบราว์เซอร์ลูกค้าเอง ไม่มีค่าใช้จ่ายเซิร์ฟเวอร์ใดๆ

## ไฟล์ในแพ็กเกจนี้

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเว็บและโค้ดทำงานทั้งหมด |
| `quests-data.js` | คลังเควสและข้อความบับเบิลของเพื่อนสุขภาพ แก้ไขได้โดยไม่ต้องเขียนโค้ด |
| `logo.png` | โลโก้ Wellnest Story ที่แสดงบนหน้าแรกและการ์ดแชร์ |
| `README.md` | ไฟล์นี้ |

**ไฟล์ทั้ง 4 ต้องอยู่ในโฟลเดอร์เดียวกันเสมอ** ถ้าขาดไฟล์ใดไฟล์หนึ่ง โลโก้หรือเควสจะโหลดไม่ขึ้น

## วิธีเพิ่ม/แก้ไขเควส (ไม่ต้องเขียนโค้ด)

เปิดไฟล์ `quests-data.js` ด้วยโปรแกรมแก้ไขข้อความทั่วไป มองหาหมวดที่ต้องการ เช่น:

```js
"เพิ่ม": [
  "เพิ่มไข่ต้ม 2 ฟองในมื้อกลางวันวันนี้",
  "เพิ่มไข่ต้ม 1 ฟองในมื้อเช้า"   // <- เพิ่มบรรทัดใหม่แบบนี้ได้เลย
],
```

เพิ่มข้อความใหม่ในเครื่องหมายคำพูด `" "` คั่นด้วยจุลภาค บันทึกไฟล์ แล้วรีเฟรชหน้าเว็บ ไม่ต้องแตะไฟล์ `index.html` เลย แนะนำให้มีอย่างน้อย 15-20 เควสต่อหมวดย่อยเพื่อไม่ให้รู้สึกซ้ำเร็วเกินไป

## วิธีเปลี่ยนเพื่อนสุขภาพจากข้อความเป็นภาพจริง (สำหรับนักพัฒนา/ทีมกราฟิก)

ตอนนี้เพื่อนสุขภาพแสดงเป็นข้อความ "Pet 1"-"Pet 6" ชั่วคราว เมื่อมีภาพประกอบ 6 ขั้นพร้อมแล้ว ให้แก้ในไฟล์ `index.html`:

1. หาฟังก์ชัน `updatePetVisual` ในส่วน `<script>`
2. แทนที่บรรทัดที่ตั้งค่า `body.textContent = "Pet " + ...` ด้วยการตั้งค่ารูปภาพ เช่นเปลี่ยน `body` จาก `<div>` เป็น `<img>` แล้วตั้ง `body.src` ตามขั้น `progress.stageIndex` (มีอาร์เรย์ `STAGE_SIZES` ที่กำหนดขนาดต่อขั้นไว้ให้แล้วในโค้ด)

## วิธีอัปโหลดขึ้น GitHub และเปิดใช้งานฟรี (GitHub Pages)

1. สร้าง repository ใหม่บน GitHub เช่น `wellnest-story-quest`
2. อัปโหลดไฟล์ทั้ง 4: `index.html`, `quests-data.js`, `logo.png`, `README.md`
3. ไปที่ **Settings → Pages**
4. Source เลือก **Deploy from a branch** → Branch: `main` → โฟลเดอร์ `/ (root)` → **Save**
5. รอ 1-2 นาที จะได้ลิงก์รูปแบบ `https://<ชื่อบัญชี>.github.io/wellnest-story-quest/`
6. ส่งลิงก์ให้ลูกค้าเปิดผ่านมือถือ แนะนำให้ Add to Home Screen เพื่อให้เปิดใช้ได้เหมือนแอป

## ข้อจำกัดที่ควรทราบ

- ข้อมูลทั้งหมด (เควส, Day Streak, ความคืบหน้าเพื่อนสุขภาพ) เก็บที่เบราว์เซอร์ของลูกค้าเอง ถ้าล้างข้อมูลเบราว์เซอร์หรือเปลี่ยนเครื่อง/เบราว์เซอร์ ประวัติจะหายและเริ่มนับใหม่ ควรแนะนำลูกค้าให้ใช้เครื่อง/เบราว์เซอร์เดิมตลอดโปรแกรม
- ยังไม่มีระบบให้ทีมงานเห็นภาพรวมความคืบหน้าของลูกค้าทุกคนจากส่วนกลาง (ต้องอัปเกรดเป็นระบบที่มีฐานข้อมูลกลางในอนาคตหากต้องการ)
- Day Streak (นับวันติดต่อกัน) และ ความคืบหน้าเพื่อนสุขภาพ (นับวันสะสม) เป็นตัวเลขคนละชุดกันโดยตั้งใจ — Day Streak รีเซ็ตเมื่อขาดวัน แต่ความคืบหน้าเพื่อนสุขภาพไม่รีเซ็ต สะสมไปเรื่อยๆ
