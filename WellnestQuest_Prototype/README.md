# 7 Days Wellnest Story Quest

เควสประจำวันคู่กับโปรแกรมลดน้ำหนัก Nutrilite — เว็บแอปสำหรับสุ่มเควส Eating Quest และ Activity Quest ให้ลูกค้าทำวันละ 1 อย่างต่อประเภท

## วิธีการทำงาน

1. หน้าแรกมีปุ่มใหญ่ 2 ปุ่ม: **อาหาร (Eating Quest)** และ **กิจกรรม (Activity Quest)**
2. กดปุ่มใดปุ่มหนึ่งที่ยังไม่ได้เลือกวันนี้ → ไปหน้าเลือกหมวดย่อย (4 หมวด)
3. เลือกหมวดย่อย → ระบบสุ่มเควส 1 อย่างจากหมวดนั้นให้ทันที
4. เควสที่สุ่มได้จะค้างอยู่บนปุ่มหน้าแรกจนถึงเที่ยงคืน (00:00) — กันไม่ให้ลูกค้าสุ่มใหม่ไปเรื่อยๆ จนกว่าจะได้เควสง่าย
5. เมื่อถึงเที่ยงคืน ระบบจะรีเซ็ตให้เลือกเควสใหม่ได้ทั้งสองประเภทโดยอัตโนมัติ
6. ลูกค้ากดปุ่ม "ทำสำเร็จแล้ว?" เพื่อติ๊กว่าทำเควสวันนี้เสร็จ ถ้าทำครบทั้ง 2 ประเภทในวันเดียวกัน วันนั้นจะถูกนับเป็นวันสำเร็จ และขึ้น 🔥 streak ต่อเนื่องที่หน้าแรก

ข้อมูลทั้งหมดเก็บไว้ใน localStorage ของเบราว์เซอร์ลูกค้าเอง ไม่มีค่าใช้จ่ายเซิร์ฟเวอร์ใดๆ

## วิธีเพิ่ม/แก้ไขเควส (ไม่ต้องเขียนโค้ด)

เควสทั้งหมดอยู่ในไฟล์ **`quests-data.js`** ไฟล์เดียว เปิดด้วยโปรแกรมแก้ไขข้อความทั่วไป (Notepad, TextEdit, VS Code) แล้วมองหาหมวดที่ต้องการ เช่น:

```js
"เพิ่ม": [
  "เพิ่มไข่ต้ม 2 ฟองในมื้ออาหารวันนี้",
  "เพิ่มผักใบเขียว 1 จานเล็กในมื้อเย็น",
  // เพิ่มบรรทัดใหม่ตรงนี้ได้เลย ห้ามลืมจุลภาค (,) ปิดท้ายบรรทัดก่อนหน้า
  "เพิ่มไข่ต้ม 1 ฟองในมื้อเช้า"
],
```

เพิ่มข้อความใหม่ในเครื่องหมายคำพูด `" "` คั่นด้วยจุลภาค บันทึกไฟล์ แล้วรีเฟรชหน้าเว็บ เควสใหม่จะพร้อมถูกสุ่มทันที ไม่ต้องแตะไฟล์ `index.html` เลย

**คำแนะนำ:** ควรมีอย่างน้อย 15-20 เควสต่อหมวดย่อย เพื่อไม่ให้ลูกค้ารู้สึกว่าเควสซ้ำเดิมเร็วเกินไป (ตอนนี้แต่ละหมวดมีประมาณ 8-10 เควสเป็นตัวอย่างเริ่มต้น)

### เพิ่มหมวดย่อยใหม่ทั้งหมวด

ถ้าต้องการเพิ่มหมวดย่อยใหม่ (เช่น หมวดที่ 6) ต้องแก้ 2 จุด:
1. เพิ่มลิสต์เควสในไฟล์ `quests-data.js`
2. เพิ่มชื่อหมวดในไฟล์ `index.html` ที่ตัวแปร `SUBCATS` (ใกล้ต้นส่วน `<script>`) — ทำตามรูปแบบเดิมที่มีอยู่ได้เลย

## วิธีอัปโหลดขึ้น GitHub และเปิดใช้งานฟรี (GitHub Pages)

1. สร้าง repository ใหม่บน GitHub เช่น `wellness-quest-app`
2. อัปโหลดไฟล์ทั้ง 4: `index.html`, `quests-data.js`, `logo.png`, `README.md`
3. ไปที่ **Settings → Pages**
4. Source เลือก **Deploy from a branch** → Branch: `main` → โฟลเดอร์ `/ (root)` → **Save**
5. รอ 1-2 นาที จะได้ลิงก์รูปแบบ `https://<ชื่อบัญชี>.github.io/wellness-quest-app/`
6. ส่งลิงก์ให้ลูกค้าเปิดผ่านมือถือ แนะนำให้ Add to Home Screen

## ข้อจำกัดที่ควรทราบ

- ข้อมูลเก็บที่เบราว์เซอร์ของลูกค้าเอง ถ้าล้างข้อมูลเบราว์เซอร์หรือเปลี่ยนเครื่อง ประวัติจะหายและเริ่มนับใหม่
- ยังไม่มีระบบให้ทีมงานเห็นภาพรวมความคืบหน้าของลูกค้าทุกคนจากส่วนกลาง (เป็นขั้นต่อไปถ้าต้องการอัปเกรด)
